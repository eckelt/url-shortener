# Sperrklinke: nur neue Struktur-Drift sperrt

Für: Bestandssoftware und heutige Altlasten blockieren nichts, trotzdem kann Drift nur sinken; Knoten ohne Spec bleiben frei, Deploys hängen am Check. Wider: Bestand wird nie erzwungen abgebaut; `twin-check` baut zwei Aggregate (≈ doppelte Laufzeit) und braucht stabile Drift-Schlüssel ohne Zeilennummern.
